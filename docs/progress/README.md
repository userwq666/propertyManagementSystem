**完成时间：** 2026-07-12

**功能清单：**

| 功能 | 状态 | 说明 |
|------|------|------|
| 用户登录 | ✅ | JWT Token认证 |
| 用户管理 | ✅ | 增删改查、分页查询、状态切换 |
| 角色管理 | ✅ | 增删改查、分页查询、菜单权限分配 |
| 菜单管理 | ✅ | 树形结构、增删改查 |
| 操作日志 | ✅ | 分页查询、日志记录 |

- sys_user（用户表）

**API接口：**

- GET /api/user/page - 用户分页列表
- POST /api/user - 新增用户
- PUT /api/user - 更新用户
- DELETE /api/user/{id} - 删除用户
- ... 更多接口见API文档

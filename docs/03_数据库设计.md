# 物业管理系统 — 数据库设计

## 1. 数据库概述

- 数据库名称：`property_management_system`
- 数据库版本：MySQL 8.0+
- 字符集：UTF-8（`utf8mb4`）
- 初始化方式：应用启动时由 `DatabaseInitializer` 按顺序自动执行 `src/main/resources/sql/` 下的初始化脚本，也可手动执行
- 通用约定：所有业务表均包含 `id`（自增主键）、`create_time`（创建时间）、`update_time`（更新时间）、`deleted`（逻辑删除，0 正常 1 删除）字段

初始化脚本编号：

| 脚本 | 内容 |
|------|------|
| 00_init.sql | 初始化前置设置 |
| 01_system.sql | 系统管理：用户、角色、菜单、权限分配 |
| 02_community.sql | 小区基础：楼栋、业主、房屋、车位 |
| 03_fee.sql | 收费管理：收费项目、缴费记录、收费通知、消费事项 |
| 04_repair.sql | 报修管理 |
| 05_complaint.sql | 投诉建议 |
| 06_equipment.sql | 设备管理：分类、设备台账 |
| 07_inspection.sql | 巡检管理：计划、关联、记录、修改留痕 |
| 08_announcement.sql | 公告通知 |
| 09_stats.sql | 统计校验脚本 |

## 2. ER 关系概览

```
sys_user ──┬── sys_user_role ── sys_role ── sys_role_menu ── sys_menu
           │
           └── community_owner（业主档案，按 user_id 关联）
                   │
                   ├── community_house（房屋，owner_id）
                   ├── community_parking（车位，owner_id）
                   ├── fee_record（缴费记录，owner_id / house_id / item_id）
                   ├── repair_record（报修，owner_id / house_id，可选）
                   └── complaint_suggest（投诉，owner_id 可选，creator_id 必填）

community_building ── community_house（building_id）

fee_item ──┬── fee_item_scope（通知范围：楼栋/房屋/业主）
           ├── fee_record（item_id）
           └── fee_notice（item_id）

equipment_category ── equipment（category_id）
equipment ──┬── inspection_plan_equipment ── inspection_plan
            └── inspection_record（equipment_id / plan_id）
inspection_plan ── inspection_plan_inspector ── sys_user（巡检员）
inspection_record ──┬── inspection_record_log（修改留痕）
                    └── repair_record（异常转报修，repair_record_id）
```

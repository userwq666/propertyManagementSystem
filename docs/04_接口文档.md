# 物业管理系统 — 接口文档

## 1. 接口规范

### 1.1 基础信息

- 基础地址：`http://localhost:8080/api`
- 数据格式：请求与响应均为 JSON（UTF-8）
- 认证方式：除登录接口外，均需在请求头携带 `Authorization: Bearer <token>`；浏览器端同时携带 `X-Tab-Id` 用于标签页级会话隔离

### 1.2 统一响应结构

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {}
}
```

| code | 含义 |
|------|------|
| 200 | 成功 |
| 400 | 参数校验失败 |
| 401 | 未登录或 Token 失效 |
| 403 | 无权限 |
| 500 | 服务器内部错误 |

### 1.3 分页参数

分页接口统一支持 `pageNum`、`pageSize` 参数，返回：

```json
{ "records": [], "total": 0, "size": 10, "current": 1, "pages": 0 }
```

## 2. 认证模块（/api/auth）

| 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|
| POST | /auth/login | 登录，返回 Token、角色、权限 | 否 |
| POST | /auth/logout | 登出，Token 加入黑名单 | 是 |
| GET | /auth/me | 获取当前登录用户信息 | 是 |

**登录请求**

```json
POST /api/auth/login
{ "username": "admin", "password": "123456" }
```

**登录响应（data 字段）**

```json
{
  "token": "eyJhbGciOiJIUzI1NiJ9...",
  "userId": 2,
  "username": "admin",
  "realName": "王经理",
  "avatar": null,
  "roles": ["property_admin"],
  "permissions": ["system:user:list", "repair:record:process", "..."]
}
```

| GET | /repair/record/{id} | repair:record:list | 详情 |
| GET | /repair/record/houses | repair:record:add | 可选报修房屋（业主限自己的） |
| GET | /repair/record/equipments | repair:record:add | 可选设备列表 |

| DELETE | /repair/record/{id} | repair:record:delete | 删除 |
| PUT | /repair/record/status | repair:record:process | 状态流转：派单/接单、结单、取消 |
| PUT | /repair/record/rating | repair:record:evaluate | 确认评价（1-5 分） |

**状态流转参数（PUT /status）**

```json
{ "id": 1, "status": 1, "handlerId": 4 }          // 派单/接单 → 处理中
{ "id": 1, "status": 2, "handleContent": "已修复", "expenseAmount": 100, "expenseType": 1 }  // 结单 → 待确认
{ "id": 1, "status": 4 }                          // 取消
```

> 结单时填写消费金额会自动生成消费事项（待审核）。

## 12. WebSocket 接口

- 连接地址：`ws://localhost:8080/ws?token=<jwt>&tabId=<tabId>`
- 握手鉴权：通过 `?token=` 与 `?tabId=` 校验 JWT 及标签页会话
- 消息格式：

```json
{ "type": "repair", "title": "新派单", "content": "...", "refId": 12, "time": 1754000000000 }
```

- 推送类型：`repair`、`complaint`、`fee`、`inspection`、`announcement`、`equipment`、`system`
- 前端收到消息后：弹出全局通知（可点击跳转对应页面），并触发列表页自动刷新

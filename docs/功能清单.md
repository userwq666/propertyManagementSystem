# 物业管理系统 — 功能清单

> 系统共 9 个业务模块 + 首页工作台，涵盖小区基础、收费、报修、投诉、设备、巡检、公告、统计与实时推送。

## 1. 首页工作台

| 功能 | 说明 |
|------|------|
| 欢迎横幅 | 按时间段问候，显示当前登录人 |
| 待办事项 | 按角色返回待办数量：管理员（待派单报修/待确认报修/待处理投诉/巡检异常/待审核消费）、财务（待收款确认/待审核消费）、维修工（待接单/处理中报修）、巡检员（待巡检任务）、业主（待缴物业费/报修待确认/投诉待确认） |
| 最新公告 | 显示最新已发布公告 |
| 实时刷新 | WebSocket 推送或写操作后自动刷新待办数量 |

## 2. 系统管理

| 功能 | 说明 |
|------|------|
| 用户管理 | 新增/编辑/删除用户、启用禁用、重置密码、关联角色 |
| 角色管理 | 角色增删改、菜单/按钮权限分配 |
| 菜单管理 | 目录/菜单/按钮权限点维护 |
| 认证 | JWT 登录、登出、当前用户信息 |

## 3. 社区管理

| 功能 | 说明 |
|------|------|
| 楼栋管理 | 楼栋档案增删改查 |
| 房屋管理 | 房屋增删改查；业主按档案过滤，只看到自己的房屋 |
| 业主管理 | 业主档案增删改查，必须关联登录账号 |
| 车位管理 | 车位增删改查；业主只看到自己的车位 |

## 4. 收费管理

| 功能 | 说明 |
|------|------|
| 收费项目 | 新增物业费项目（单价/单位/通知范围），启用停用，停用后可删除 |
| 项目发布 | 按范围（全体/楼栋/房屋/业主）自动生成待缴费账单，同步生成收费通知并实时广播 |
| 收费通知 | 通知增删改查、发布 |
| 收费记录 | 待缴费账单列表；财务线下收款后填报实缴金额/方式/备注（支持部分缴费）；逾期标记；业主只看到自己的账单 |
| 消费事项 | 维修工结单时申报支出，财务审核通过后对业主公示 |

## 5. 报修管理

| 功能 | 说明 |
|------|------|
| 报修提交 | 业主选择房屋报修；巡检员异常一键报修 |
| 派单/接单 | 管理员派单或维修工抢单（条件更新防并发抢单） |
| 结单 | 维修工填写处理内容结单，可申报消费事项 |
| 确认评价 | 报修人确认并评分（1-5 分）；超时 24 小时自动完成 |
| 设备联动 | 报修关联设备自动置故障/维修中/恢复正常 |

## 6. 投诉建议

| 功能 | 说明 |
|------|------|
| 提交投诉 | 任何人均可提交（类型：投诉/建议/咨询） |
| 受理处理 | 管理员受理并指定处理人，回复解决方案 |
| 确认评价 | 投诉人确认完成并评价 |

## 7. 设备管理

| 功能 | 说明 |
|------|------|
| 设备分类 | 分类维护 |
| 设备台账 | 设备档案增删改查、状态调整 |
| 设备记录 | 只读汇总：设备信息 + 巡检计划 + 巡检记录 + 维修记录，对所有角色开放 |

## 8. 巡检管理

| 功能 | 说明 |
|------|------|
| 巡检计划 | 管理员制定计划（周期/设备/指定巡检员），启停、删除（停用后） |
| 记录生成 | 定时任务按周期生成巡检记录（每日/每周/每月/每季/半年/每年/一次性） |
| 巡检记录 | 二维矩阵打卡：行=设备，列=周期日期；巡检员首次填写，管理员修改需原因留痕 |
| 异常闭环 | 异常一键生成报修单；维修结单/完成后自动标记"已处理" |

## 9. 公告通知

| 功能 | 说明 |
|------|------|
| 公告管理 | 公告增删改查、发布/下架、置顶 |
| 定时发布 | 到预约时间自动发布并广播 |

## 10. 统计分析

| 功能 | 说明 |
|------|------|
| 总览卡片 | 维修/设备/人员/费用/投诉/巡检关键指标 |
| 图表展示 | 维修类型与状态环形图、设备状态环形图、角色分布环形图、费用月度趋势折线图、投诉状态环形图、巡检结果环形图 |
| 待办接口 | 首页待办事项按角色统计 |

## 11. 实时推送

| 功能 | 说明 |
|------|------|
| WebSocket | JWT 握手鉴权，断线 5 秒重连 |
| 消息推送 | 报修/投诉/费用/巡检/公告/设备/系统状态变更实时通知，点击跳转对应页面 |
| 列表刷新 | 推送或写操作成功后，列表页自动重新加载 |

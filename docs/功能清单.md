## 附：技术架构

| 层 | 技术 |
|----|------|
| 后端框架 | Spring Boot 4.0.7 |
| 安全认证 | Spring Security + JWT |
| ORM | MyBatis-Plus 3.5.15 |
| 数据库 | MySQL 8.0 |
| 前端框架 | Vue 3 + Vite |
| UI 组件库 | Element Plus |
| 状态管理 | Pinia |
| 图表 | ECharts |

### 分层规范

```
Controller（入参DTO） → Service 接口（业务签名） → ServiceImpl（Domain操作） → Mapper
                                                          ↓
Controller（出参VO） ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← VO转换
```
